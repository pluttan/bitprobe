# bitprobe

**Посмотреть, что однобитная модель на самом деле сделала со своими весами**

</div>

Консольный инструмент, который сравнивает низкобитную квантованную модель с полноточной моделью, из которой она получена. Тензоры читаются прямо из удалённых safetensors-репозиториев через HTTP range-запросы, поэтому ни одна из моделей не скачивается целиком — по сети идут только изучаемые срезы. Вместе с прямым сравнением считается и то, что дал бы наивный знаковый квантизатор: интересен не столько отрыв квантованной матрицы от оригинала, сколько то, как этот отрыв соотносится с очевидной базовой линией.

## ■ Возможности

- ❖ **Удалённый доступ к тензорам** — читается заголовок safetensors (несколько килобайт), затем по диапазону байт забирается только нужный тензор или срез строк; модель на 27B можно изучать с ноутбука
- ❖ **Сравнение с базовой линией** — каждое измерение выводится рядом с наивной поблочной знаковой и тернарной квантизацией, поэтому метод, который обыгрывает простое округление, отличим от метода, который не обыгрывает
- ❖ **Определение группы** — размер группы масштабирования выводится из повторяющихся модулей значений в строке, без чтения метаданных
- ❖ **Профиль переворотов знака** — доля перевёрнутых знаков по децилям величины исходных весов, показывает, разменяли ли мелкие веса на точность в другом месте
- ❖ **Профиль по глубине** — обход шаблона тензоров по всем слоям с отклонением на каждой глубине
- ❖ **Корректная работа с BF16** — базовые модели раздаются в BF16, квантованные в F16; чтение одного как другого даёт правдоподобный мусор, поэтому оба формата декодируются явно

## ■ Как это работает

```
1. Читаются заголовки safetensors обоих репозиториев — килобайты, не гигабайты
2. Вычисляется диапазон байт нужного тензора или его первых N строк
3. BF16 или F16 декодируется во float32
4. Базовый тензор квантуется наивно, чтобы получить точку отсчёта
5. Выводятся косинусная близость, совпадение знаков, относительная ошибка,
   отношение масштабов, доля нулей и распределение переворотов по децилям
```

## ■ Использование

```bash
# Установка
make install

# Структура хранения квантованной модели: размер группы, dtype, разреженность
venv/bin/python3.12 main.py info prism-ml/Bonsai-1.7B-unpacked

# Сравнение одного тензора с полноточной базой
venv/bin/python3.12 main.py compare \
    prism-ml/Bonsai-1.7B-unpacked Qwen/Qwen3-1.7B \
    model.layers.0.mlp.gate_proj.weight

# Перевороты знака по величине весов
venv/bin/python3.12 main.py flips \
    prism-ml/Bonsai-1.7B-unpacked Qwen/Qwen3-1.7B \
    model.layers.0.mlp.gate_proj.weight

# Отклонение по слоям
venv/bin/python3.12 main.py profile \
    prism-ml/Bonsai-1.7B-unpacked Qwen/Qwen3-1.7B --limit 8

# Всё сразу
make demo
```

Пример вывода `compare`:

```
model.layers.0.mlp.gate_proj.weight  [256, 2048]
  cos(model, base)        +0.4886
  cos(naive binary, base) +0.7909
  cos(naive ternary, base)+0.8926
  sign agreement          71.0%
  relative error          1.354
  naive relative error    0.612
  scale vs mean|w|        1.990
  zero fraction           0.0%
```

`--rows` задаёт число строк, читаемых из каждого тензора (по умолчанию 256, `0` — весь
тензор), `--group` — размер группы масштабирования (по умолчанию 128).
